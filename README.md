# money-camp

Kids finance education game. Ten short days, one badge each, built for ages 9 to 12.
Everything lives in `index.html` — open it in a browser, no build step. Progress saves in the browser.

## How a day works

Recall question from the day before → the idea → a prediction you must lock in → a hands-on activity → stamp the badge.

## Around the ten days

- **Camp coins** — paid once each for right answers, called predictions, badges and missions.
- **Vault** — coins left in it earn 10% at every new badge, so waiting pays inside the game itself.
- **Trading post** — stickers for the camp flag, priced so you cannot afford them all.
- **Campfire quiz** — eight review questions from badges already earned; pays coins once a day.
- **Word cards** — sixteen key terms that unlock as badges are stamped.
- **Real-life missions** — one off-screen task per badge.
- Sound effects (with a mute button), confetti, read-aloud lessons and a printable certificate.

Notes for parents are in the "Notes for the grown-up" section at the bottom of the page.
